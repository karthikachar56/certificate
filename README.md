# CertiCraft Studio PRO

A luxury, interactive web application to design, customize, edit, and print high-resolution certificates with live WYSIWYG editing, dynamic seals, and digital signatures.

## Key Features

1. **WYSIWYG Direct Click-to-Edit**:
   - Click directly on any text on the certificate (Recipient name, Certificate title, Course/Accomplishment, Description, Dates, Signatories, Certificate ID) to edit in real time.
   - Real-time 2-way synchronization with sidebar controls.

2. **Sidebar Customizer**:
   - **Template Presets**: Certificate of Completion, Certificate of Appreciation, Certificate of Excellence & Achievement, Certificate of Participation, Diploma of Honor, or Blank Slate.
   - **Themes & Borders**: Royal Gold & Navy, Emerald Silk, Crimson Executive, Modern Minimalist Slate, Vintage Parchment, and Tech Obsidian.
   - **Typography**: Regal Roman (Cinzel), Editorial Serif (Playfair Display), Academic (Cormorant Garamond), Modern Sans (Montserrat, Outfit), and Calligraphy/Script (Great Vibes, Alex Brush, Pinyon Script).
   - **Color Customizer**: Live color pickers for gold accents, border tones, and background tint.
   - **Orientation**: Switch between Landscape (A4 standard) and Portrait.

3. **Seals, Emblems & Verification QR**:
   - Official Gold Crest, Academic Laurel Wreath, Guaranteed Ribbon, or Clean.
   - Editable circular seal text path.
   - Real-time QR Code generator with customizable verification URL.
   - Auto-generated unique Certificate ID (`CERT-YYYY-XXXXX`).

4. **Digital Signatures & Organization Logo**:
   - Type calligraphy signatures.
   - Draw custom signatures live on an HTML5 canvas signature pad.
   - Upload custom signature image files.
   - Upload institution or company logo.

5. **Print & Export Options**:
   - **Direct Print (`Ctrl+P` or Print button)**: Perfectly scaled for A4 paper with background graphics preserved and UI controls stripped away automatically.
   - **Download PDF**: Standard A4 vector PDF format ready for emailing or archiving.
   - **Download PNG / JPEG**: Ultra-sharp 300 DPI graphics for sharing on LinkedIn or digital badges.
   - **Bulk Mode**: Paste multiple recipient names to batch print or download a multi-page PDF in one click!

## Running the Web App

The application is already running at:
```
http://localhost:3000
```

To run manually at any time:
```powershell
node server.js
```
Or simply double-click and open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox).
